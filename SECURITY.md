# Security Policy

## Supported versions

Security fixes are provided for the latest `1.x` release of `optaeo/module-aeo`.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [support@optaeo.ai](mailto:support@optaeo.ai) with the subject `Security: Magento module`. Do not open a public issue for a suspected vulnerability.

Include the affected module version, Magento or Adobe Commerce version, PHP version, and steps to reproduce where possible. We will acknowledge the report and coordinate a fix or disclosure timeline with you.
